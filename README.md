# pymongo-api

## Как запустить

Переходим в каталог sharding-repl-cache.
Запускаем mongodb и приложение

```shell
docker compose up --build
```

После старта всех контейнеров автоматически запустится скрипт, который инициализирует кластер MongoDB, добавит реплики,
заполнит коллекцию данными, выведет общее число документов, а также количество документов в каждой реплике:

```shell
./scripts/mongo-setup.sh
```

Запускать его вручную не надо.

## Как проверить

### Если вы запускаете проект на локальной машине

Откройте в браузере http://localhost:8080

Получить документы: http://localhost:8080/helloDoc/users
